## 6. Limitations of this drill

   starting a container from a GHCR digest. The restore path itself is
   reference-agnostic: it starts from whatever `images.postgres.compose_pin`
   records, after `docker image inspect` resolves it locally — a re-run after the
   re-pin exercises that with no script change. No pull is ever attempted.

   harness database's absent blobs, the frozen fixture partitions, the three
   capture moments, the expected globals error, the empty journal, the
   restored API's own writes, the unencrypted bundle.
