## 5. What is verifiable, and what is not

VERIFIABLE (done here): the raw index bytes hash to the pinned digests; the children the gate scans are the ones named; the children's
source annotations equal the Docker Official Images library entries; the redis source commit's signature is valid on GitHub; the provenance
attestations name the same source commit and the Docker Official Images builder; the installed packages carry every watched fix (inventory/).
NOT verifiable here, stated: the postgres source commit is unsigned (the Docker Library Bot's commits are not GPG-signed); the attestations are
unsigned in-toto statements attached to the index (Docker Official Images do not publish cosign/sigstore signatures for docker.io/library
manifests; nothing in this repository's C19 anchor covers them); the build is declared non-reproducible by its own provenance; the Alpine
package bytes are trusted through Alpine's signed APKINDEX at build time, which this repository cannot re-verify after the fact.
