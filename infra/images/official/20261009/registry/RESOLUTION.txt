Finding: NO patched official image exists.
  * postgres:18-alpine (the pinned variant and tag family) has NOT moved since the pin: it still resolves
    to 77f58511…, built 2026-09-17, whose gosu is 1.19 built with go1.24.6 on both platforms
    (../gosu/IDENTITY.txt: the same bytes as 2026-09-22).
  * Every official postgres 18 variant (alpine3.24, alpine3.23, trixie, bookworm) installs gosu 1.19; the
    newest builds (2026-10-06, Debian variants) predate the advisories (2026-10-08). gosu 1.19 is built
    with go1.24.6, inside both affected ranges.
  * There is therefore nothing to re-pin to; a re-pin to another variant would not change the gosu bytes.
    The recheck (scripts/gate/check-patched-images.mjs) watches the OS-package fixes, not gosu; it would
    report postgres as "the configured pin is the compatible official image" — correct for what it
    watches, and silent on these two advisories by design.
